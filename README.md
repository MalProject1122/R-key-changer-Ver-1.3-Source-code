# R-key changer

パソコンでいま鳴っている音（YouTube・ブラウザなど）を、
**その場でキー（音の高さ）だけ変えて聴ける**、Windows用の小さなツール
です。

- 曲のファイルは要りません。いつも通り再生するだけです
- **ダウンロードや録音は一切しません。** 鳴っている音をその場で
  加工して鳴らし直しているだけです
- 「この曲、自分にはちょっと高いな」を確かめるのに使えます

## 必要なもの

- Windows
- Python 3.11 以降
- [VB-CABLE](https://vb-audio.com/Cable/)（無料の仮想オーディオデバイス。
  パソコンの中に音を通すための見えないケーブルを1本増やすもの、と
  思ってください）

## セットアップ

### exeをそのまま使う場合（Pythonのインストール不要）

Releasesから `R-key changer.exe` をダウンロードして実行するだけです。

### ソースから実行する場合

```bash
pip install -r requirements.txt
python main.py
```

### いずれの場合も

VB-CABLEをまだ入れていない場合は、[vb-audio.com](https://vb-audio.com/Cable/)
から「VB-CABLE Virtual Audio Device」をダウンロードして入れ、パソコンを
再起動してください（無償・1回だけ）。

## 使い方

exeなら `R-key changer.exe` をダブルクリック、ソースから実行するなら
`python main.py` で起動します。

1. ウィンドウを開くと、既定の出力デバイスが自動でCABLE Inputへ
   切り替わります（Windowsのサウンド設定を自分で開く必要はありません）
2. 聴きたい曲を、いつも通り再生します
3. **入力**に `CABLE Output`、**出力**に自分のヘッドホンかスピーカーを
   選びます（たいていは最初から正しく選ばれています）
4. **「▶ 開始」**を押すと、音がヘッドホンから聞こえてきます
5. **▲▼ボタン**（またはキーボードの↑↓）でキーを変えます。曲を止めずに
   その場で高さが変わります。動かせる範囲は `-12`〜`+12`（1オクターブ）
6. **LIVE SPACE** を ON にすると、ライブ会場で聴いているような音場に
   なります。**Preset** から `Studio` / `Small Live House` /
   `Concert Hall` / `Arena` / `Stadium` を選ぶだけで、会場の大きさ・
   初期反射・残響・エコー・広がりがまとめて切り替わります。
   `Arena (Best Seat)` / `Stadium (Best Seat)` は「一番音が良く聞こえる席」
   で、ボーカルをクリアに保ったまま会場の大きさを感じられる音質優先版です。
   `Live 1`〜`Live 5` は会場の規模がだんだん大きくなるバリエーションで、
   広さ・天井の高さ・壁の材質（`Live 5` は野外で壁なし）が段階的に
   変わります。特定の実在会場を再現したものではありません。
   **Audience**（FRONT / MIDDLE / BACK）で客席のどこで聴くかを選べます。
   細かく変えたいときは **Room Size**・**Early Refl.**（初期反射）・
   **Reverb**（残響）・**Echo**・**Width**（左右の広がり）を、さらに
   「詳細 ▼」で Depth・Pre-Delay・Decay・Damping・Echo Time・Feedback
   を動かしてください（動かすと Preset は `Custom` になります）。
   **Output** はヘッドホンかスピーカーかを選びます。ヘッドホンのときは
   **Binaural** を ON にすると、反射音と残響が HRTF で「頭の外」の
   それぞれの方向から聞こえるようになります（歌声そのものには掛けない
   ので音色は変わりません。合わないと感じたら OFF に戻してください）。
   Windows 側の「立体音響（Windows Sonic 等）」と併用すると二重に
   広がるため、どちらか一方をおすすめします
7. **EQ**タブでは、10バンドのイコライザーで音色を整えられます
   （31Hz〜16kHz、各 -12〜+12dB）。**プリセット**から `Flat` / `Vocal` /
   `Karaoke` / `Bass Boost` / `Treble Boost` / `Clear` / `Rock` を選べます。
   スライダーを手で動かすと `Custom` になります。**RESET** を押すとすべて0dBに戻り、
   **ON/OFF** でEQを通すかどうかを切り替えます（OFFにするとEQをまったく通しません）。
   グラフには、いまの設定での周波数特性が表示されます
8. 気に入った音響とEQの設定は、**マイプリセット**に名前を付けて保存
   できます。音響タブの「💾 マイプリセットに保存」を押し、名前を入れて、
   「音響の設定を保存」と「EQの設定を保存」のうち保存したいほうに
   チェックを入れます（片方だけでも保存できます）。保存したプリセットは、
   音響タブの「マイプリセット」から読み込めます。🗑 を押すと削除します。
   キー（半音）は曲ごとに変わるので、マイプリセットには保存しません
9. 終わったら「■ 停止」を押すか、ウィンドウを閉じてください。既定の
   出力デバイスは自動で元に戻ります。Windows の「既定のデバイス」と
   「既定の通信デバイス」を別々の機器にしている場合も、それぞれ起動前の
   機器へ戻ります。アプリが強制終了した場合でも、次にアプリを開いて
   「■ 停止」を押すか閉じたときに元へ戻ります

### 画面上部のボタン

| ボタン | 内容 |
|---|---|
| ⚙ | 詳細設定（音声のバッファサイズ 1024 / 2048 / 4096 を選べます。音飛びが多いときは大きくすると減りますが、そのぶん遅延が増えます） |
| 📊 | メモリとCPUの使用率を表示します（1秒ごとに更新。直近60秒のグラフ付き） |
| ？ | 説明書（使い方ガイド）を開きます |

画面上部の「はじめる前に」欄には、接続状態が緑（デバイス接続中）／赤
（デバイスの接続に失敗）で表示されます。一度でも接続に成功すると、
次回起動時からはこの手順欄が自動で畳まれます。

## うまくいかないときは

| 症状 | 確認すること |
|---|---|
| 元の音とキーを変えた音が二重に聞こえる | 入力が `CABLE Output` になっていますか（`CABLE Input` を出力に選んでしまうと、音がケーブルの中をぐるぐる回るため選べないようにしてあります） |
| タスクバーの音量バーを動かしても音量が変わらない | アプリ使用中は既定の出力が CABLE Input になっているため、タスクバーでは実際のスピーカー／ヘッドホンの音量を変えられません。「🎚 キー」タブの「🖥 出力音量」で調整してください |
| 何も聞こえない | 曲は再生されていますか。「入力」が `CABLE Output` になっていますか |
| 「音声デバイスを開けませんでした」と出る | デバイス名のうしろに `[Windows WDM-KS]` と書かれたものは開けないことがあります。同じ名前で `[MME]` や `[Windows WASAPI]` と書かれたほうを選んでください |
| 「接続が切れたため停止しました」と出る | ヘッドホン等を抜き差しすると自動で停止します（既定の出力も元に戻ります）。接続し直して「一覧を更新」→「▶ 開始」を押してください（「一覧を更新」で、挿し直した機器も一覧に出るようになります） |
| 原因の分からない不具合 | `%LOCALAPPDATA%\R-key changer\logs\r-key-changer.log` に記録が残っています。問い合わせの際に添えていただくと調査しやすくなります（パスに Windows のユーザー名が含まれます） |
| 「共通のサンプリング周波数が…」と出る | Windowsのサウンドの詳細設定で、CABLEとスピーカーの形式（例: 48000 Hz）をそろえてください |
| 設定を元に戻したい・設定ファイルが壊れた | `app_settings.json`（exe と同じフォルダ）を削除すると初期設定で起動します。壊れた値や範囲外の値が入っていても、アプリはその項目だけを初期値に戻して起動します |
| アプリを終了したあと音が出ない | 通常は自動で元に戻りますが、まれに反映が遅れて音が出ないことがあります。次の順に試してください。<br>1. **アプリをもう一度開いて、そのまま閉じ直す**（開く/閉じるたびに既定デバイスを切り替え直す動きになり、これだけで直ることがあります）<br>2. それでも直らなければ、設定 ＞ システム ＞ サウンド ＞ 出力 で、**一度別のデバイスに変えてからスピーカーへ戻す**（同じデバイスを選び直すだけだと反映されないことがあるため、一度切り替えを挟みます） |

## 注意点

このツールが移調するのは「パソコンから聞こえる音」だけです。マイクで
拾った自分の声までは変えられないので、弾き語りのように声と一緒に
鳴らして確認する用途には向きません。あくまで「曲を聴いて、自分の声域に
合うか確かめる」ための道具だと思ってください。

### ⚠ Apple Musicでは利用できません

Windows版のApple Musicアプリで試したところ、**音楽は流れるものの、キー変更・音響・EQが
かからない**ことを確認しました。Apple Musicの音がVB-CABLEを通らず、スピーカーへ
直接届いているためと考えられます（既定の出力を切り替えても、Apple Music側が
それに追従しない可能性があります）。

また、Apple Music再生中に本ツールを起動すると、曲が次々に切り替わる・
「不明なエラーが起きました」と表示される等の症状が出ることもあります。
YouTubeなど、他のサービスをご利用ください。

## 仕組み（技術的な話）

Windowsの既定の出力デバイスを一時的にCABLE Inputへ切り替えて音を
横取りし、WSOLA方式の時間伸縮アルゴリズムでピッチだけをリアルタイムに
動かして、そのまま実際のスピーカー/ヘッドホンへ再生し直しています。
OSの音声ドライバやシステム全体の音質設定を書き換えているわけではなく、
このアプリを通っている間だけ加工がかかる仕組みです。

音声は次の順番で処理されます。

```
入力 → キー変更（WSOLA） → EQ → LIVE SPACE → 出力
```

- **キー変更**：WSOLA（numpy）
- **EQ**：RBJ方式のpeakingフィルタ（Q=1.0）を10段つないだbiquadカスケード。
  速さを出すため、この部分はC言語で書いてあり（`native/biquad_eq.c` → `biquad_eq.dll`）、
  Pythonから `ctypes` で呼び出しています。DLLが読み込めない場合（ウイルス対策ソフトに
  隔離された場合など）は、EQだけが無効になり、それ以外の機能はそのまま使えます
- **LIVE SPACE**：鏡像法による初期反射、FDN残響、球頭モデルHRTF（バイノーラル）、Mid/Side処理
- **メモリ・CPUモニター**：C言語（`native/sysinfo.c` → `sysinfo.dll`、Win32 API）

AI（機械学習）は使っていません。処理はすべて従来の信号処理（DSP）です。

## 開発者向け

### 安全対策

- 設定ファイルやマイプリセットに NaN・Infinity・型の違う値が入っていても、
  その項目は初期値に戻します（Python 側と C の DLL 側の両方で確認しています）
- 処理結果に NaN・Infinity が混ざった場合は、そのブロックを無音にして
  EQ と音響の内部状態をリセットします（爆音やノイズを出さないため）
- EQ の係数更新（GUI スレッド）と音声処理（音声スレッド）は、C を呼ぶ区間だけを
  短いロックで直列化しています
- 起動前の既定出力デバイスを、3つの役割（Console / Multimedia / Communications）
  ごとにデバイスID（`IMMDevice.GetId()`）で `app_settings.json` に保存し、終了時に
  役割ごとに戻します。元の機器が見つからない役割だけ、デバイス名での復元に切り替えます

### DLLの再ビルド

`native/*.dll` はビルド済みのものをリポジトリに含めています。Cのソースを
変更したときだけ、再ビルドしてください。**MSVC 64bit** が必要です（MinGWの `gcc` は
32bitのため使えません）。Visual Studio 2022 Build Tools の `vcvars64.bat` を
読み込んでから、`native` フォルダで次を実行します。

```bat
cl /utf-8 /LD /O2 /Fe:biquad_eq.dll biquad_eq.c
cl /utf-8 /LD /O2 /Fe:sysinfo.dll sysinfo.c psapi.lib
```

ソースには日本語のコメントが入っているので、`/utf-8` を必ず付けてください（付けないと
MSVC がコメントを CP932 として読み、警告 C4819 が出て、行が壊れることがあります）。

どちらのDLLも、依存しているのは `KERNEL32.dll` だけです（VC++再頒布パッケージは要りません）。

### exeのビルド

```bash
python -m PyInstaller "R-key changer.spec" --noconfirm
```

`dist/R-key changer.exe` が作られます。
